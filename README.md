## Build
```bash
# setup
npm ci
# watch
npm run watch
# production build
npm run build
# make package
npm run build:package
```

## Load Extension
```bash
# 1. Open Chrome and go to chrome://extensions/
# 2. Enable Developer mode
# 3. Click "Load unpacked"
# 4. Select the public/ folder after build
```
